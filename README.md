# تطبيق موكب أمنا الزهراء

<p align="center">
  <img src="assets/logo/logo.png" width="200" alt="شعار موكب أمنا الزهراء">
</p>

تطبيق موبايل لإدارة موكب أمنا الزهراء عليها السلام: المشتركون والمتبرعون، المبالغ والدفعات، التقارير القابلة للطباعة، ومنشورات بنمط إنستغرام. مبني بـ **Flutter** وقاعدة بيانات **Supabase**، يعمل على أندرويد و iOS، ويعمل **بلا إنترنت** مع مزامنة تلقائية عند عودة الاتصال.

---

## الشاشات

| # | الشاشة | المحتوى |
|---|--------|---------|
| ١ | **الرئيسية** | كارت المبلغ الكلي العريض (يُفتح بالضغط لعرض التفصيل)، كارتا عدد المتبرعين وعدد المشتركين، ثم قائمة عمودية بأعلى ١٠ متبرعين |
| ٢ | **المشتركون** | كارتان — المتبرعون والمشتركون — كل واحد يفتح قائمة كاملة فيها بحث بالاسم أو الهاتف، وفلترة شهري/سنوي، وترتيب بالمبلغ أو الاسم، وحالة السداد |
| ٣ | **المنشورات** | واجهة بنمط إنستغرام: شريط ستوريز بأقسام، منشورات بعدة صور، إعجاب وتعليق ومشاركة، أرشيف السنوات |
| ٤ | **التقارير** | كارتان مربعان بحواف ناعمة، وكل واحد يفتح جدولاً احترافياً بشعار الموكب وتاريخ الطباعة، قابلاً للطباعة والمشاركة |
| ٥ | **الإعدادات** | الملف الشخصي، الوضع الليلي والنهاري، إدارة المستخدمين والصلاحيات والحظر، مسح الذاكرة المؤقتة |

قبلها **واجهة ترحيب** بشعار الموكب، و**وضع زائر** يفتح التطبيق بلا تسجيل ويرى المنشورات فقط.

## الأدوار والصلاحيات

| الدور | يرى الإحصائيات | يرى الأسماء | يضيف ويعدّل | ينشر | يدير المستخدمين |
|-------|:---:|:---:|:---:|:---:|:---:|
| **زائر** (بلا حساب) | ✗ | ✗ | ✗ | ✗ | ✗ |
| **عضو** معتمد | ✓ | ✗ | ✗ | ✗ | ✗ |
| **ناشر** | ✓ | ✗ | ✗ | ✓ | ✗ |
| **مسؤول مالي** | ✓ | ✓ | ✗ | ✗ | ✗ |
| **مدير عام** | ✓ | ✓ | ✓ | ✓ | ✓ |

- الزائر يستطيع **الإعجاب** على المنشورات بلا تسجيل، أما **التعليق** فيتطلب حساباً.
- التسجيل مفتوح للجميع، لكن الحساب يبقى **بانتظار موافقة المدير** قبل أن يرى أي رقم.
- العضو المعتمد يرى **الأرقام دون الأسماء** — مفروض في قاعدة البيانات عبر دالة مجمّعة، لا بإخفاء عناصر في الواجهة.

## البنية التقنية

```
lib/
├── core/
│   ├── config/       إعدادات التطبيق ومفاتيح Supabase
│   ├── providers/    مزوّدات Riverpod للحالة
│   ├── router/       مسارات go_router مع شريط تنقّل ثابت
│   ├── storage/      Hive مشفّر + الإعدادات المحلية
│   ├── theme/        الألوان والثيم بوضعيه
│   └── widgets/      الخلفية والكروت الزجاجية
├── features/         كل ميزة بمجلدها (data / presentation)
└── shared/
    ├── models/       النماذج والتعدادات والصلاحيات
    └── widgets/      مكوّنات مشتركة
supabase/
└── schema.sql        الجداول وسياسات RLS والدوال والمشغّلات
```

**الحزم الأساسية:** `flutter_riverpod` للحالة · `go_router` للتنقّل · `supabase_flutter` للخلفية · `hive_ce` للتخزين المحلي المشفّر · `flutter_secure_storage` لمفتاح التشفير · `local_auth` لقفل البصمة · `pdf` و `printing` للتقارير · `cached_network_image` للصور

**الخط:** IBM Plex Sans Arabic مضمّن بأربعة أوزان — **لا يُحمَّل وقت التشغيل** ليعمل التطبيق أوفلاين.

**الشعار:** يُعرض بخلفيته البيضاء الأصلية داخل لوحة بحواف ناعمة وحدّ ذهبي، ليبدو البياض عنصر تصميم مقصوداً على الخلفية الداكنة. وفي التقارير المطبوعة يُعرض بلا لوحة.

**الألوان:** مستخرجة قياساً فعلياً من بكسلات شعار الموكب — ذهبي `#C6A77B` وبرونزي `#8D7759` وعنابي `#7D493A` وفيروزي `#3D6D78` — فوق سلّم أخضر داكن.

## التشغيل من الصفر

### ١. تهيئة قاعدة البيانات

أنشئ مشروعاً جديداً على [supabase.com](https://supabase.com)، ثم من **SQL Editor** نفّذ ملف `supabase/schema.sql`. هذا ينشئ كل الجداول والفهارس وسياسات RLS والمشغّلات ودالة الإحصائيات.

### ٢. إنشاء أول مدير

سجّل حساباً من التطبيق، ثم نفّذ في SQL Editor **مرة واحدة**:

```sql
update public.profiles
   set role = 'admin', status = 'approved'
 where id = (select id from auth.users where email = 'بريدك@هنا');
```

بعدها يستطيع المدير الموافقة على بقية الحسابات من داخل التطبيق.

### ٣. تشغيل التطبيق

```bash
flutter pub get

flutter run \
  --dart-define=SUPABASE_URL=https://xxxx.supabase.co \
  --dart-define=SUPABASE_ANON_KEY=eyJhbGci...
```

> **بلا مفاتيح** يعمل التطبيق ببيانات تجريبية كاملة، فتستطيع تجربة كل الواجهات والأدوار قبل إعداد قاعدة البيانات.

## بناء ملف APK

```bash
flutter build apk --release \
  --obfuscate --split-debug-info=build/symbols \
  --dart-define=SUPABASE_URL=https://xxxx.supabase.co \
  --dart-define=SUPABASE_ANON_KEY=eyJhbGci...
```

الناتج في `build/app/outputs/flutter-apk/app-release.apk`.

يوجد أيضاً خط أنابيب في `.github/workflows/build-apk.yml` يبني الـAPK تلقائياً عند كل دفعة إلى `main`، وتجده في تبويب **Actions** ضمن ملفات البناء.

### iOS

الكود متوافق مع iOS بالكامل، لكن توليد ملف IPA يتطلب **جهاز macOS مع Xcode** وحساب Apple Developer:

```bash
flutter build ipa --release --obfuscate --split-debug-info=build/symbols
```

## الأمان

| الطبقة | التنفيذ |
|--------|---------|
| **صلاحيات السيرفر** | Row Level Security على كل جدول، والصلاحيات مفروضة في PostgreSQL لا في التطبيق |
| **التخزين المحلي** | Hive مشفّر بـ AES-256، ومفتاحه في Android Keystore / iOS Keychain |
| **قفل التطبيق** | بصمة أو رمز عند كل فتح للمستخدمين المسجّلين |
| **الهندسة العكسية** | تشويش الكود عبر `--obfuscate` وفصل رموز التصحيح، وإزالة السجلات في الإصدار |

> **ملاحظة صريحة:** مفتاح Supabase العام (anon) **مُصمَّم ليكون مكشوفاً** — أي شخص يفكّ أي تطبيق سيجده، وهذا طبيعي. الحماية الحقيقية أن السيرفر لا يثق بالتطبيق أبداً: لو استخرج أحدهم المفتاح فلن يحصل على أكثر مما يحصل عليه أي زائر عادي، لأن كل صلاحية تُفحص في قاعدة البيانات.

## الأداء

الهدف ٦٠ إطاراً في الثانية، والقرارات المتخذة لتحقيقه:

- **الزجاجي بحساب** — `BackdropFilter` مكلف على الـGPU ويُعاد حسابه كل إطار، لذا يُستخدم على الكروت **الثابتة** فقط (كروت الرئيسية، شريط التنقّل). داخل القوائم المتمرّرة يُستبدل بتدرّج مطلي مسبقاً بنفس المظهر تماماً.
- **التوهّج بالتدرّج لا بالتمويه** — توهّج الخلفية الأخضر مرسوم بـ `RadialGradient` يُرسم مرة واحدة، لا بتمويه يُحسب كل إطار.
- **الصور المصغّرة** — `cached_network_image` مع `memCacheWidth` محدّد، فلا تُفكّ صورة بحجم كامل داخل قائمة طويلة.
- **`RepaintBoundary`** على كل كارت لعزل إعادة الرسم عن بقية الشجرة.
- **`ListView.builder`** في كل القوائم — لا يُبنى إلا ما هو مرئي.

### الحماية من الـoverflow

- كل الأرقام الكبيرة داخل `FittedBox` فتتقلّص بدل أن تفيض.
- كل النصوص المتغيّرة لها `maxLines` و `TextOverflow.ellipsis`.
- مقياس خط النظام محدود بين ٠٫٩ و ١٫٢٥ فلا يكسر التخطيط إذا كبّر المستخدم خط هاتفه.
- جداول التقارير: عمود الاسم مثبّت مع تمرير أفقي لبقية الأعمدة، والطباعة تعرض كل الأعمدة بحجم A4.
