# Workspace Agent Rules — مشروع موكب أمنا الزهراء

- **التوثيق الإلزامي**: عند تنفيذ أو إنجاز أي تعديل، ميزة جديدة، تحسين بصري، أو إصلاح برمجي في هذا المستودع، يجب تحديث ملف `CLAUDE (1).md` فوراً بالقرارات والتغييرات والتفاصيل الهندسية المستحدثة ليظل الدليل مرجعاً كاملاً ودقيقاً.
